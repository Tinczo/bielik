# 06: Presety odsłuchu dla utworów

**What to build:** Muzyk zapisuje poziomy źródeł swojego odsłuchu jako preset dla danego utworu i przywołuje go jednym stuknięciem. Zgłosił Wiktor jako coś, co „mogłoby się kiedyś przydać”.

Specyfikacja v1 zostawiła presety poza zakresem. W triage trzeba ustalić, gdzie je trzymać (w telefonie czy w projekcie REAPERa) i czy wystarczy ręczne przywołanie.

**Blocked by:** None (can start immediately)
