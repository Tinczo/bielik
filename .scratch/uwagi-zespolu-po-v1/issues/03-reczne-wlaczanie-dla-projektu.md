# 03: Ręczne włączanie Rozszerzenia dla każdego projektu

**What to build:** Rozszerzenie udostępnia odsłuchy dopiero po ręcznym włączeniu dla danego projektu, więc otwarcie innego projektu nie wystawia go telefonom przez przypadek. Zgłosił Wiktor.

Do wyjaśnienia w triage: z rozmowy nie wynika jednoznacznie, na którą wiadomość odpowiadała ta uwaga, czyli czy chodzi o przełączanie projektów, czy o dostęp do cudzych odsłuchów (ticket 04). Dziś Rozszerzenie działa zawsze i pokazuje odsłuchy aktywnego projektu. To była świadoma decyzja ze specyfikacji v1.

**Blocked by:** None (can start immediately)

**Status:** needs-triage

- [ ] Ustalono, jaki problem ma rozwiązać ten mechanizm.
- [ ] Niewłączony projekt nie udostępnia odsłuchów.
- [ ] Włączenie jest zapisane w projekcie i przetrwa jego ponowne otwarcie.
